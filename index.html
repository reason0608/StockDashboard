🛠 2分鐘建立對接：零代碼指南

  1. 開啟你的 Google 試算表。
  2. 點選上方選單的 「擴充功能」 $\rightarrow$ 「Apps Script」。
  3. 刪除裡面所有預設程式碼，將下方 這個腳本 (點此複製) 貼進去：
    4. /* 請將此段代碼貼到 Google Apps Script 編輯器中 */
function doGet() {
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var result = {};
  
  // 1. 讀取現金流水帳
  var sheet1 = ss.getSheetByName("users_cash_flow");
  result.cashFlow = getSheetData(sheet1);
  
  // 2. 讀取交易紀錄
  var sheet2 = ss.getSheetByName("daily_transactions");
  result.transactions = getSheetData(sheet2);
  
  // 3. 讀取現有持股庫存
  var sheet3 = ss.getSheetByName("stock_inventory");
  result.inventory = getSheetData(sheet3);
  
  return ContentService.createTextOutput(JSON.stringify(result))
    .setMimeType(ContentService.MimeType.JSON);
}

function doPost(e) {
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var params = JSON.parse(e.postData.contents);
  var sheetName = params.targetSheet; // "users_cash_flow" 或 "daily_transactions"
  var sheet = ss.getSheetByName(sheetName);
  
  if (!sheet) {
    return ContentService.createTextOutput(JSON.stringify({status: "error", message: "工作表不存在"}))
      .setMimeType(ContentService.MimeType.JSON);
  }
  
  sheet.appendRow(params.rowData);
  return ContentService.createTextOutput(JSON.stringify({status: "success"}))
    .setMimeType(ContentService.MimeType.JSON);
}

function getSheetData(sheet) {
  if (!sheet) return [];
  var data = sheet.getDataRange().getValues();
  var keys = data[0];
  var list = [];
  for (var i = 1; i < data.length; i++) {
    var obj = {};
    for (var j = 0; j < keys.length; j++) {
      var val = data[i][j];
      // 處理日期格式
      if (val instanceof Date) {
        val = Utilities.formatDate(val, Session.getScriptTimeZone(), "yyyy-MM-dd");
      }
      obj[keys[j]] = val;
    }
    list.push(obj);
  }
  return list;
}

💡 100% 排除錯誤步驟：

【可能原因 1】您的網址在複製時被截斷（最常見）

Google Apps Script 的部署 ID 固定為 **56 個字元**。如果網頁偵測到您的網址太短（例如只有 48 個字元），Google 就會引導您到錯誤頁面或拒絕連線，導致瀏覽器跳出 Failed to fetch 錯誤。
👉 Correct template format: https://script.google.com/macros/s/AKfycb...[完整56個字元].../exec

【可能原因 2】部署權限忘記設為「所有人」

1. 回到 Google Sheets 擴充功能的 Apps Script 畫面。
2. 點選右上角 「部署」 $\rightarrow$ 「管理部署」。
3. 點選右側的 「編輯 (鉛筆圖示)」。
4. 將最底下的「誰有權限存取」改為 「所有人 (Anyone)」。
5. 點擊 「部署」 並在完成後複製新產生的 URL 貼回網頁設定。

【可能原因 3】試算表 Tab 分頁名字不符

請檢查你的 Google 試算表底部，工作表分頁名字必須精準符合，多一個空格、大小寫錯都不行：
- users_cash_flow (現金流水帳)
- daily_transactions (每日交易紀錄)
- stock_inventory (庫存表)
